Local presence is caller-ID selection. When enabled, the Dialer prefers an eligible number with a suitable area-code relationship to the recipient, subject to available numbers and policy.

It does not change the recipient's phone number, invent a caller identity, or guarantee that a carrier will display the call as trusted.

## Before a call

1. Confirm that your administrator has assigned permitted caller numbers.
2. Review the Call from selection and local-presence preference.
3. If no suitable local number is available, check the configured fallback before calling.

Caller numbers can be temporarily unavailable while another session owns them. Do not bypass a number lock by repeatedly starting the same call.

Local presence may make a number more familiar to the recipient, but it cannot promise pickup or prevent every spam label. Review [call outcomes](/analytics/) alongside the actual caller number used, rather than judging performance from the preference switch alone.
