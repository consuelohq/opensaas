## Prepare the queue

1. Choose the correct GoHighLevel pipeline and stage.
2. Review the queue preview and any ineligible or missing-phone entries.
3. Choose the Call from number and local-presence preference.
4. Select the available dialing mode and line count.
5. Check microphone readiness, then start the queue.

GoHighLevel opportunities provide queue membership and deal context. Their linked contacts provide the callable person and phone identity. The server resolves the eligible pool and selects the next batch; the line count is not the size of that pool.

## During the queue

Use the available pause, resume or stop controls deliberately. The active batch uses a stable snapshot while CRM data may refresh in the background. Changes to a pipeline stage do not silently replace a conversation already in progress.

Complete the [outcome](/outbound/wrap-up/) after a connected call before continuing. If the queue is empty, check pipeline selection, contact phone data, calling windows and previous attempts before assuming the application lost the contacts.
