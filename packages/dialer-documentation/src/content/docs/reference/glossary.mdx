title: Glossary
description: Use consistent terms for calling and recovery.
status: preview
---

| Term | Meaning |
| --- | --- |
| Pipeline-stage queue | Eligible stage opportunities linked to callable contacts. |
| Fanout / line count | Requested maximum concurrent outbound attempts in a batch. |
| Local presence | Caller-number selection using the recipient and permitted number-pool policy. |
| Rep readiness | Explicit willingness to receive inbound work on healthy devices. |
| Capacity | A rep's unit of work, protected through reservation, connection and wrap-up. |
| Offer | A bounded invitation to accept a waiting caller. |
| Generation | Assignment version checked when an action commits. |
| Connected | Confirmed media connection, beyond acceptance. |
| Unknown outcome | A dispatched provider operation whose result is not established. |
| Reconciliation | Checking provider facts and persisted state to resolve uncertainty. |
| Abandonment | A caller leaving the waiting process before service. |
| Callback obligation | Durable work from an authorized callback request. |
| Disposition | The structured outcome recorded after a call. |
