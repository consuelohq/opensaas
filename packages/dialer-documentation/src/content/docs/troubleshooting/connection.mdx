## Reconnecting repeatedly

Open Dialer from its installed entry inside the correct GoHighLevel location. The application needs signed context from its host; a standalone URL or generic custom-menu iframe does not supply the same identity.

1. Check that GoHighLevel is signed in and showing the intended location.
2. Return to the installed Dialer entry.
3. Use Retry once and wait for current state.
4. If Reconnecting immediately returns, stop repeating it and ask your administrator to inspect the session exchange.

The operator is ready only when the server confirms Ready for inbound. A healthy forwarding phone does not establish a healthy browser session.

## Data or carrier errors

Authorization, provider restrictions and missing queues are different problems. Record the error and time. Your administrator can check installation scopes, provider readiness and server logs.

Do not share session tokens or change OAuth callbacks as a shortcut. Follow [first-call verification](/start/first-call/) after recovery.
