## Gather useful context

Note the selected location, action, visible error and approximate time. Include any call or session reference when contacting your administrator or [support](mailto:support@consuelohq.com).

Check current state before redialing an uncertain call. An application timeout and a confirmed carrier rejection require different recovery steps.
