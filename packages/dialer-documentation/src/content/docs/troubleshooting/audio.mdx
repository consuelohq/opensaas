## Before calling again

Check browser microphone permission, the selected input device, speaker or headset output, mute controls and system audio settings.

## Test deliberately

1. Stop new dialing while investigating.
2. Confirm the browser detects the intended microphone.
3. Reopen Dialer through the installed GoHighLevel app if voice registration needs recovery.
4. Arrange one test with a consenting recipient.
5. Confirm audio in both directions, end the test and check history.

An iframe can load while microphone delegation is missing. Ask your administrator to check the installed page's permissions if no prompt appears.

For inbound phone answering, verify the configured destination and screening prompt separately from browser audio.

Refreshing a browser does not prove the carrier call ended. Check any active or uncertain call before starting another test. For session errors, see [connection troubleshooting](/troubleshooting/connection/).
