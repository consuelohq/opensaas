These are preview docs. A feature described here may require an enabled plan, configured number, healthy device or administrator activation. Code and simulated tests do not establish that every customer can use it today.

| Area | Current boundary |
| --- | --- |
| Embedded outbound calling | The app supports direct calls and pipeline-stage queues. Installation and live calling must be verified for your location. |
| Multi-line dialing and local presence | Availability depends on your plan, permitted numbers and calling configuration. |
| Inbound routing | Preview. The server and operator workflow need explicit number, queue and rep configuration plus live validation. |
| Callback and voicemail | Preview. They are available only when configured and enabled for the number. |
| Call history | Stored records and lifecycle state are available through the application contracts. Confirm the records visible in your installation. |
| Transcription | Conditional on authorization, workspace settings, provider configuration and plan eligibility. |
| Live AI coaching and uploaded-transcript feedback | Planned. These are not self-service features promised by this release. |

## Evaluate the product

Ask your administrator which features are enabled, then test one complete workflow at a time. Check [billing](/billing/) for the current commercial offer. No answer-rate uplift, instant connection or guaranteed delivery is promised by these guides.
