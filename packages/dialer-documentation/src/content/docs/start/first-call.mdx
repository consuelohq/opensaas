## Prepare a test

Use a recipient who has agreed to the test. Start with one line, a configured caller number, and headphones. Check that your browser microphone works before initiating the call.

## Place the call

1. Open Dialer in the connected GoHighLevel location.
2. Choose a direct contact or Single dial and verify the intended recipient.
3. Review the Call from number. If local presence is available, check which caller number will be used.
4. Start the call once and wait for its current status.
5. When connected, confirm that both people can hear each other.
6. End the call and record its outcome during [wrap-up](/outbound/wrap-up/).

Then open [call history](/analytics/history/) and confirm that the call ended with the expected outcome.

## If the result is uncertain

An error or timeout does not always mean the carrier failed to create a call. Check the current call state before trying again. If the screen cannot recover, ask your administrator to reconcile it; repeated clicking can create additional calls.

Once this works, move to [pipeline-stage queues](/outbound/queues/).
