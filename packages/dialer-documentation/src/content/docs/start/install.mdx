## Before you begin

Ask your administrator to confirm the location, installed Dialer app, calling plan and permitted caller numbers. Installation and number activation are administrator tasks; opening a public application URL does not create a connected account.

## Open Dialer

1. Sign in to [GoHighLevel](https://app.gohighlevel.com/).
2. Select the connected location.
3. Open its installed Consuelo Dialer entry. Some installations may still display the older Mercury Dialer app name.
4. Allow the application to finish connecting before choosing a contact or queue.
5. For browser calling, allow microphone access when prompted and check the selected input device.

You should see data from the location you selected. If the application repeatedly asks to reconnect, follow [session troubleshooting](/troubleshooting/connection/).

## Installation is still being validated

This is preview documentation. The public self-service installation journey is being validated. Use the installation link supplied by your administrator rather than an old bookmark or copied OAuth URL. A generic custom-menu iframe does not replace the installed app's signed user context.

Need the location connected? [Contact support](mailto:support@consuelohq.com) with its name and the step that failed. Do not send passwords or provider secrets.
