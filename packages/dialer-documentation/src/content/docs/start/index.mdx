Consuelo Dialer brings calling into GoHighLevel. Reps work from customer and pipeline context while the server handles dialing and call state.

## Before you begin

You need access to the GoHighLevel location your administrator has connected, permission to use Dialer, and an enabled calling plan. For browser calling, use a supported browser with a working microphone and headphones.

## Your first session

1. [Set up GoHighLevel](/start/install/) with your administrator.
2. Open Dialer inside that location and check that customer data loads.
3. [Make one outbound call](/start/first-call/) to a consenting test recipient.
4. Complete wrap-up before starting a queue or enabling additional lines.

A successful first call includes audible two-way media, a finished call, and an outcome in history. A ringing screen alone does not establish that setup is complete.

For receiving calls, use the separate [inbound readiness guide](/inbound/readiness/). Going ready is different from opening the application.
