# Consuelo Dialer website

Focused Astro/Bun marketing surface for Consuelo Dialer.

## Scope

- Direct-response Dialer landing page
- Connector-neutral CRM positioning
- Dialer plan-structure page
- Private/Tailscale preview during development

This package intentionally reuses the visual language of `packages/consuelo-website` without carrying over the OS/blog product surface.

## Commands

```sh
bun run --cwd packages/consuelo-dialer-website dev
bun run --cwd packages/consuelo-dialer-website build
```

No production domain or deployment target is approved by this package yet.
