## Serialized update protocol

Worker 23 is the sole writer of this ledger. Domain and synthesis reviewers post findings to GitHub and their own report, then submit the proposed ledger row to Worker 23. They do not edit this file concurrently.

- IDs are deterministic: `23<DOMAIN>-R<ROUND>-<NNN>` with one sequence per authoritative domain and review round.
- Worker 23 rejects duplicate IDs and checks path/risk fingerprints for duplicate or conflicting findings before appending.
- Secondary seam reviewers identify the authoritative domain and transfer the finding; only the authoritative reviewer owns the final disposition.
- Rows are append-only within a review round. Disposition updates preserve the prior value in the GitHub thread and name the verifying candidate SHA.
- Worker 23h may consume the ledger only after Worker 23 confirms all expected domain reports were serialized and conflict checks passed.
