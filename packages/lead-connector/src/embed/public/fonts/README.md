# Interface fonts

Inter Variable 5.2.8 and Bodoni Moda Variable 5.2.7 match the Consuelo website.
The unmodified Latin upright WOFF2 files are stored as ASCII base64 sources so
repository task publication preserves their binary bytes. build-embed.ts decodes
them into /fonts/interface.woff2 and /fonts/wordmark.woff2. Both use the SIL Open
Font License; the original licenses are included here and copied to the build.
The canonical Consuelo logo is copied from consuelo-website/public/logo.svg.
