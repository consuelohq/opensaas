This page lists current security contracts. Use the conceptual pages before changing policy.

## Route auth modes

| Mode | Current meaning |
| --- | --- |
| `public` | The registered route may be served without a user session, normally as an intentional static snapshot. |
| `required` | The route requires an accepted authentication path before use. |
| `workspace-session` | The route requires a valid signed-in workspace session. |
| `signed-connector` | The internal hop requires platform-generated signed connector proof. |

Route resolution is by normalized hostname and longest matching path prefix. Route records can be `active` or `disabled`; hostname records can be `active` or `revoked`.

## Credential states

| State | Accepted? | Meaning |
| --- | --- | --- |
| `active` | Until expiry and policy checks pass | Current credential |
| `rotated` | No | Replaced by newly issued material |
| `revoked` | No | Explicitly terminated |

Current persisted records keep verifier material or a bearer hash, scoped identity fields, timestamps, and safe usage metadata. Raw private material is not returned by status operations.

## Current lifetimes

| Proof | Current window |
| --- | --- |
| Signed request timestamp and nonce replay window | 5 minutes |
| Device authorization session | 15 minutes |
| Connector bootstrap material | 10 minutes |
| OAuth code and access token | Defined by the hosted OAuth service constants; clients should honor returned expiry rather than hard-code it |

A nonce is consumed only by a request that reaches the applicable verification stage. Old nonces are pruned outside the verification window.

## Permission tiers

`read`, `draft`, `write`, `execute`, `external`, and `admin` describe increasing side-effect risk. Scope authorization and action approval remain separate checks.

## Signed request inputs

Current machine proof binds:

- credential identity;
- method and path;
- request-body digest;
- timestamp and nonce;
- workspace, subject, device, connector, connection, caller, and app identity;
- required scope.

## Stable local verification errors

| Code | Meaning |
| --- | --- |
| `BAD_SIGNATURE` | The signature does not match the request and credential. |
| `EXPIRED_TIMESTAMP` | The request timestamp is outside the allowed window. |
| `REPLAYED_NONCE` | The nonce was already accepted inside the replay window. |
| `WORKSPACE_MISMATCH` | The request and credential name different workspaces. |
| `SUBJECT_MISMATCH` | The subject does not match. |
| `DEVICE_MISMATCH` | The device does not match. |
| `CONNECTOR_MISMATCH` | The connector does not match. |
| `CONNECTION_MISMATCH` | The connection does not match. |
| `CALLER_MISMATCH` | The caller does not match. |
| `APP_MISMATCH` | The app does not match. |
| `MISSING_SCOPE` | The credential does not grant the required route or tool scope. |
| `UNKNOWN_TOOL_SCOPE` | The tool cannot be classified from the current manifest and is denied. |
| `TOKEN_EXPIRED` | The credential passed its expiry. |
| `TOKEN_ROTATED` | The credential was replaced. |
| `TOKEN_REVOKED` | The credential was terminated. |

## Hosted edge errors

| Code | Meaning |
| --- | --- |
| `WORKSPACE_ROUTE_REGISTRY_UNAVAILABLE` | The hosted service cannot safely resolve a workspace route. |
| `WORKSPACE_HOSTNAME_ROUTE_NOT_FOUND` | The hostname or path is not registered and active. |
| `WORKSPACE_EDGE_AUTH_REQUIRED` | The route requires an auth mode the current request did not satisfy. |
| `WORKSPACE_HOSTNAME_OS_CONNECTOR_OFFLINE` | The registered OS connector is unavailable. |
| `WORKSPACE_HOSTNAME_RESERVED` | The hostname belongs to a protected platform surface. |
| `WORKSPACE_SITE_SNAPSHOT_UNAVAILABLE` | An approved static snapshot could not be read. |

Public error responses are bounded and should include a request identifier without exposing backend targets or credentials.

## Local defaults

| Setting | Current default |
| --- | --- |
| Local OS host | `127.0.0.1` |
| Local OS port | `46321` |
| Public workspace transport | Managed edge plus outbound connector when provisioned |
| Legacy generic bearer fallback | Not accepted |

Do not copy credential values, private connector origins, or internal signing headers into a support report. Preserve the stable code, request or trace ID, route, timestamp, and intended workspace.
