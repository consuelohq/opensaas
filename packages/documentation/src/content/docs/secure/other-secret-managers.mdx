> **Native Consuelo support: Planned**

Apple Keychain is the current macOS pattern. Consuelo can later add adapters for 1Password, Bitwarden, Doppler, Infisical, and organization-specific secret systems without changing every provider tool.

## The adapter contract

A secret-manager adapter should expose capabilities such as:

```text
secrets.status
secrets.resolveForProcess
secrets.rotateReference
secrets.revokeReference
```

It should return references and status, not plaintext secrets. Provider tools should request a named credential at execution time and receive it only inside the local process boundary.

## Ask your agent

```text
Use the official secret-manager CLI or SDK on this local node.
Authenticate it with the narrowest supported account, vault, project, or service account.
Create an adapter that resolves a named secret only inside the provider process.
Return present, missing, invalid, or denied status without revealing the value.
Add tests for locked sessions, missing references, expired credentials, and denied vault access.
```

## Available today

You can use an official local interface before a native Consuelo adapter ships:

- [1Password CLI](https://www.1password.dev/cli)
- [Bitwarden CLI](https://bitwarden.com/help/cli/)
- [Doppler CLI](https://docs.doppler.com/docs/cli)
- [Infisical CLI](https://infisical.com/docs/cli/overview)

Keep the secret manager independent from provider permissions. Access to a vault item does not automatically authorize the agent to run the tool that consumes it.
