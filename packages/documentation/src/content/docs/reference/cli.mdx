The installed user-facing command is `consuelo`.

```bash
consuelo help
```

Running `consuelo` without a command shows local OS status.

## Commands

| Command | Purpose |
| --- | --- |
| `consuelo status` | Show installation and runtime status. |
| `consuelo install` | Install and configure Consuelo OS. |
| `consuelo restart` | Restart Consuelo OS services. |
| `consuelo update` | Check for or install OS updates. |
| `consuelo repair` | Repair the current installation. |
| `consuelo rollback` | Roll back to the previous verified release. |
| `consuelo add skill` | Install bundled skills; opens a picker when no names are supplied. |
| `consuelo remove skill` | Remove selected bundled skills; opens a picker when no names are supplied. |
| `consuelo channel` | Show or change the release channel. |
| `consuelo updates` | Manage update notification preferences. |
| `consuelo uninstall` | Remove Consuelo OS from the machine. |
| `consuelo dev` | Development and recovery commands. |

## Skill management

Interactive:

```bash
consuelo add skill
consuelo remove skill
```

Direct:

```bash
consuelo add skill branch browser
consuelo remove skill teach
```

See [Install a skill](/build/skills/install-a-skill/) for selection, materialization, and local-modification preservation behavior.

## Update examples

```bash
consuelo update --check
consuelo update --yes
consuelo update --channel beta --check
```

Available release channels are `stable`, `beta`, `canary`, `dev`, and `nightly`.

### Restart and update gateway reconciliation

`consuelo restart` reconciles the local gateway from the currently active runtime before reloading services. A successful `consuelo update` activates the verified candidate first, then runs gateway reconciliation and reload from that newly active runtime rather than from the older process that initiated the update. This prevents stale proxy configuration from being restored after an otherwise successful update.

Private workspace pages depend on signed Workspace Edge headers surviving that local gateway hop. A lifecycle command now fails if the activated runtime cannot complete its gateway reconciliation instead of silently continuing with stale configuration.

## Common options

```text
--json       Machine-readable output where the command supports it
--quiet      Suppress human-readable output
-h, --help   Print help
```

Command-specific options include update/channel flags, rollback/uninstall dry-run controls, and development reset confirmation. `consuelo help` is the authoritative compact command index for the installed version.

## Agent runtime interface

The OS package also contains lower-level agent/operator runtime entrypoints such as `scripts/os.ts`. Agents normally reach those capabilities through MCP and the typed OS facade rather than asking a user to run the Bun script directly. Treat the public `consuelo` command above as the user-facing lifecycle CLI.
