Consuelo OS gives every agent the same workspace: the same tools, files, steering, and record of what happened. Start with a local installation, give the workspace a name, then connect one agent over MCP.

<Note>
  Consuelo OS is in preview. The self-service local installer currently supports macOS. If you need an always-on managed runtime, read [Nodes](/nodes/) after you have the workspace mental model.
</Note>

## What the installer creates

A normal local installation creates a Consuelo home at `~/.consuelo` containing:

- workspace and node configuration;
- a local SQLite database under `node/db/`;
- the selected skills and installed tool registry;
- steering files, scripts, logs, runs, artifacts, and Sites;
- generated security configuration;
- an MCP command that supported local agents can run.

Existing configuration and user-owned steering, skills, and tools are preserved when the installer runs again.
