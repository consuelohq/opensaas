Local and Consuelo Cloud describe where the workspace's home node runs. They are not two different products, and the current setup experience is not equally self-service.

| | Local | Consuelo Cloud |
| --- | --- | --- |
| Home node | Your supported Mac | Managed with the Consuelo team |
| Current setup | Self-service installer | Assisted provisioning |
| Public installer behavior | Installs the local runtime | Opens the contact page and exits |
| Local files and database | Stored under your Consuelo home | Defined during managed provisioning |
| Best starting point | Individual preview use and local tools | A continuously managed home node or team deployment |

## Local

Choose **local** when you want Consuelo OS to run on your Mac.

The installer creates the Consuelo home, node database, tools, skills, steering, Sites, and generated security configuration locally. With an approved workspace, it can also receive the scoped connector information needed for the public workspace route.

Local installation currently supports macOS. The optional LaunchAgents keep the OS available while you work without leaving the installer terminal open.

Start with [Install Consuelo OS](/start/install-consuelo-os/).

## Consuelo Cloud

Choose **cloud** when the home node should be operated with Consuelo rather than installed on the current Mac.

Today, the public bootstrap does not provision a self-service Cloud runtime. It prints that Cloud is **handled by the Consuelo team**, opens [consuelohq.com/contact](https://consuelohq.com/contact/), and exits before downloading local source or installing dependencies.

That boundary matters: selecting **cloud** in the installer is a handoff, not a completed installation.

## Local can still use managed services

“Local” does not mean “disconnected.” An approved local workspace can have a Consuelo workspace identity and a managed public route while its home node and primary state remain on the Mac.

Likewise, “Cloud” does not mean that every connected tool or node must run in one hosted process. Detailed node topology belongs in [Connect](/connect/), and the exact trust boundaries belong in [Secure](/secure/).

## Which should you choose?

Choose **local** when:

- you have a supported Mac;
- you want to start immediately;
- tools need access to files or software on that Mac;
- you are comfortable operating the home node during preview.

Choose **Consuelo Cloud** when:

- you need a managed home node;
- the home node should not depend on one person's Mac;
- you are planning a team deployment;
- you need Consuelo to help define the current hosting and access model.
