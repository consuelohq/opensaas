ChatGPT is the current self-service cloud-agent connection. It reaches the same workspace tools through HTTPS instead of running the local stdio command.

## Before you connect

Complete the managed workspace flow during installation. The local node must be online for live OS tools to work, and the launcher should show a copyable MCP URL.

The stable central endpoint is:

```text
https://os.consuelohq.com/mcp
```

A managed workspace can also expose its workspace-specific `/mcp` URL. Use the URL shown by your launcher rather than guessing a hostname.

## Connect in ChatGPT

1. Open the workspace launcher.
2. Follow its **ChatGPT** link to ChatGPT connector settings.
3. Add the MCP URL shown by the launcher.
4. Complete the Consuelo OAuth approval in the browser.
5. Return to ChatGPT and enable the connector for the conversation or workspace where you need it.

The OAuth flow resolves the signed-in Consuelo account to an approved workspace. It does not ask you to paste a local credential into ChatGPT.

## Verify

Ask ChatGPT to list the Consuelo tools available through the connector, then make a harmless read-only call. A successful connection proves both OAuth and the route to the active node.

The local Settings page records ChatGPT as connected when generated `chatgpt-mcp.json` configuration is present, but a real tool call is the stronger end-to-end check.

## What ChatGPT can reach

ChatGPT receives only the tools exposed by the effective OS manifest and current policy. Connecting ChatGPT does not automatically connect GitHub, Gmail, Slack, or another service.

## Troubleshooting

- **OAuth returns to ChatGPT but tools fail:** confirm the local node and connector transport are running.
- **Wrong workspace appears:** sign in with the Consuelo account that owns the intended workspace and repeat approval.
- **The launcher has no MCP URL:** the install may have fallen back to a local-only workspace. Complete managed authorization first.
- **Tools changed but ChatGPT still shows the old list:** reconnect or refresh the connector so ChatGPT performs discovery again.

## Disconnect

Remove or disable the connector in ChatGPT. For a complete revocation, also revoke the Consuelo-side grant when that control is available to your workspace. Removing the ChatGPT UI entry alone does not shut down the local node.
