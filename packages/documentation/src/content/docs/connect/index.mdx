Consuelo OS separates the things that **call** your workspace from the external systems those calls can **use**:

- **Agents** are the applications that call OS tools.
- **Applications** are the external systems those tools can work with.

That distinction matters. Connecting Claude Code does not grant access to Gmail, and adding a provider credential does not decide which computer runs the work.

Where Consuelo runs is its own top-level concern. Use [Nodes](/nodes/) for local computers, managed cloud nodes, presence, default-node selection, and routing.

## Choose what you are connecting

| You want to… | Go to |
| --- | --- |
| Use the workspace from ChatGPT or a local coding agent | [Agents](/connect/agents/chatgpt/) |
| Work with Google Workspace, GitHub, deployment platforms, CRMs, data systems, or other providers | [Applications](/connect/apps-and-services/) |
| Choose which local or cloud node runs the work | [Nodes](/nodes/) |

## Current support at a glance

**Available now through Consuelo tools**

- ChatGPT through the workspace HTTPS MCP endpoint;
- Codex, Claude Code, Cursor, OpenCode, Factory Droid, and Gemini CLI through local MCP stdio;
- GitHub, Linear, read-only Sentry investigation, outbound Slack posts, and part of the Railway workflow.

**Available today through an official CLI or API**

- Google Workspace through `gog`;
- Cloudflare, Vercel, Datadog, Snowflake, Supabase, Salesforce, Stripe, Twilio, HubSpot, Notion, and GoHighLevel through their documented local interfaces;
- additional providers when your agent builds a small typed tool from the official contract.

The service pages separate **native Consuelo support** from **what you can use today**. Planned tools are labeled as planned; the underlying CLI or API path remains practical and explicit.

## Start with one agent

Install OS and connect one local agent first: [Connect your first agent](/start/connect-your-first-agent/). Return here to give that agent access to the services where your work already lives. Use [Nodes](/nodes/) when you want to add another runtime or change where calls execute.
