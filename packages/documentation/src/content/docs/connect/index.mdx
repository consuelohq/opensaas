Consuelo OS separates three kinds of connection:

- **Agents** are the applications that call OS tools.
- **Connectors** give those tools access to an external service.
- **Nodes** are the computers that run the local OS runtime for a workspace.

That distinction matters. Connecting Claude Code does not grant access to Gmail, and adding a GitHub credential does not register another computer as a node.

## Choose what you are connecting

| You want to… | Go to |
| --- | --- |
| Use the workspace from ChatGPT or a local coding agent | [Agents](/connect/agents/chatgpt/) |
| Give OS a supported external-service capability | [Connectors](/connect/connectors/) |
| Understand which computer runs the work | [Nodes](/connect/nodes/how-nodes-work/) |

## Current support at a glance

**Ready now**

- ChatGPT through the workspace HTTPS MCP endpoint;
- Codex, Claude Code, Cursor, OpenCode, Factory Droid, and Gemini CLI through local MCP stdio;
- the GitHub workspace tool when GitHub authentication is available;
- outbound Slack messages through a configured webhook;
- managed home and member nodes created by workspace authorization.

**Assisted or not yet self-service**

- Google Drive, Gmail, and Google Calendar service access;
- additional service connectors;
- Consuelo-hosted cloud nodes.

The pages in this section say when setup is automatic, manual, assisted, or unavailable. They do not treat a planned capability as connected.
