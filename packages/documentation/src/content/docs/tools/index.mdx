A **tool** is one operation an agent can call through Consuelo OS. Tools have stable names, typed inputs, capability metadata, timeouts, and execution policies.

Start with [How tools work](/build/tools/how-tools-work/) if you want the calling model. Open [Tool List](/tools/tool-list/) when you already know roughly what you need and want the complete alphabetical surface.

## Core tool areas

- [Workspace](/build/tools/workspace/) covers files, tasks, repository work, and the typed workspace facade.
- [Browser](/build/tools/browser/) covers web and browser automation.
- [Office](/build/tools/office/) covers productivity workflows.
- [Media](/build/tools/media/) covers media operations.
- [Workflows](/build/workflows/) explains how several operations are coordinated into a repeatable job.
- [Sites](/sites/) covers creating, previewing, and publishing workspace-backed pages.

## Discovery over guessing

Agents should use `tools.search` when a capability is not already in the core surface. The generated manifest is the source of truth for what is callable now; prose docs are an explanation layer, not a substitute for the manifest.
