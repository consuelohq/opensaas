Sites is the local review surface for work produced through Consuelo OS. It turns generated HTML, typed reader content, and artifact-backed output into pages that are easier to open and share with another person than a raw file path or database record.

A Site is not a second workspace and it is not a general web-hosting service. The source remains in your workspace. Sites materializes a reviewable copy under your Consuelo home and records published pages in a local version registry.

## What Sites creates

The default Consuelo home keeps Sites under:

```text
~/.consuelo/sites/
```

The main surfaces are:

| Surface | Local path | Purpose |
| --- | --- | --- |
| Launcher | `sites/index.html` | Opens the workspace launcher generated during setup or refresh. |
| Pages | `sites/pages/` | Holds current pages, immutable versions, and a page index. |
| Office | `sites/office/` | Lists durable artifacts such as reports, documents, and generated files. |
| Traces | `sites/traces/` | Loads recent execution traces from the local gateway when it is available. |
| Settings | `sites/settings/` | Shows the current local OS settings snapshot. |
| Diffs and docs | `sites/diffs/`, `sites/docs/` | Reserved local surfaces that can be regenerated by OS. |

The page registry lives at `sites/.data/pages/registry.json`. Section leases live beside it in `sites/.data/pages/leases.json`.

## The basic workflow

```text
create source
  → render typed content when needed
  → inspect the output locally
  → publish a versioned page
  → verify the current page and registry
```

Start with [Create a site](/sites/create-a-site/) for the complete path. Use [Pages and content](/sites/pages-and-content/) when choosing a page kind or coordinating edits between agents.

## Check the current state

Use the installed OS package from your Consuelo home:

```bash
export CONSUELO_HOME="${CONSUELO_HOME:-$HOME/.consuelo}"
bun run --cwd "$CONSUELO_HOME" os -- sites status --json
```

The result reports the Sites directory, page registry, generated surfaces, and whether their current files exist. It does not create missing files.

To generate or refresh the local surfaces:

```bash
bun run --cwd "$CONSUELO_HOME" os -- sites refresh --json
```

`sites refresh` is repeatable. It rebuilds OS-owned local surfaces from current state without deleting workspace configuration or user-owned tools and skills.

<Note>
  Publishing with the local `sites` command writes to your Consuelo home. A managed public workspace hostname is a separate platform operation; see [Domains](/sites/domains/).
</Note>
