## acceptance criteria

- [ ] At desktop widths, virtualized rows, header, and scroll content span the same actual width: no blank right gutter/column drift; Session gets more width while Input/Output stay in the initial view, remaining columns remain horizontally reachable.
- [ ] At phone widths, one visible Time label only; Time/Tool/Session readable without horizontal scroll; tablet retained.
- [ ] Raycast Option+0..9 never activates OS routes; bare digits no longer steal navigation. Preserve contextual help/keyboard row controls; optional route digits require explicit Ctrl+Shift+DigitN.
- [ ] Tooltip-bearing row cells show pointer cursor, stay clickable and show concise intent/target/result previews instead of only code character count; avoid secrets. Full raw stays in inspector.
- [ ] Keyboard arrow navigation owns focus even when rows scroll beneath a stationary pointer; repeated arrows/Enter work; intentional pointer movement restores hover.
- [ ] All 25 muted session colors reachable across varied distinct identities, deterministic per session.
- [ ] No query or network regressions; profile render/prefetch before speculative performance changes.
