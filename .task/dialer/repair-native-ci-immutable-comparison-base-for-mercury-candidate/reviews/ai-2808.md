## summary
This PR primarily modifies the CI/CD pipelines for the Dialer and LeadConnector Worker. It introduces a "Worker-only" release path (`dialer_worker_only`) and a dedicated `release-dialer-ui` job to allow UI-only updates to be deployed to Cloudflare without triggering a full Railway backend restart. It also updates the macOS runner version in the OS runtime publish workflow and includes a large number of task-tracking metadata files (`.task/`).

## issues

1. severity: 🟡 warning
   - `.github/workflows/consuelo-production-release.yaml` (Lines 72-148)
   - **Issue**: The logic for `qa_only` and `ui_only` relies on an explicit whitelist of file paths. This is fragile; any new file added to `packages/dialer-server/src/lab/` or `packages/lead-connector/src/embed/` that isn't manually added to these lists will cause the classifier to default to a full `release=true`, potentially causing unnecessary Railway restarts.
   - **Fix**: Use glob patterns (e.g., `packages/dialer-server/src/lab/**`) instead of listing every single file.

2. severity: 🟢 nit
   - `.github/workflows/consuelo-os-runtime-publish.yaml` (Lines 64, 284, 402)
   - **Issue**: The runner is updated to `macos-26`. While likely correct for the environment, ensure this version is available across all GitHub runner environments used by the team to avoid "runner not found" errors.

3. severity: 🟢 nit
   - `.github/workflows/consuelo-production-release.yaml` (Lines 424-428)
   - **Issue**: Use of `bunx wrangler@4.135.0`. Pinning the version is good for stability, but ensure this version is synchronized with the local development environment to prevent "it works locally but fails in CI" scenarios.

## good
- **Safe Deployment**: The addition of a `frontend_only` path is a significant improvement to deployment safety, preventing backend disruptions for simple CSS/UI tweaks.
- **Verification**: The `release-dialer-ui` job includes a robust verification step that `cmp`s the deployed assets against the local build, ensuring the exact source is deployed.
- **Input Validation**: The `workflow_dispatch` now explicitly errors if `dialer_worker_only` is true but the target is not `dialer`.

## verdict
REQUEST_CHANGES

**Reason**: The file-path whitelists in the release classifier are too granular and will lead to frequent CI "false positives" (triggering full releases for minor lab/UI changes) as the project grows. Please replace specific file lists with directory globs.
